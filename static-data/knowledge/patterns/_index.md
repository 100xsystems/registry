# Design Patterns

208 proven solutions to recurring design problems. Organized from simple (creational) to complex (distributed).

## Top 10 Must-Know Patterns

1. **[Factory](/knowledge/patterns/factory)** — Create objects without specifying exact class
2. **[Singleton](/knowledge/patterns/singleton)** — Ensure single instance
3. **[Observer](/knowledge/patterns/observer)** — Publish-subscribe notifications
4. **[Strategy](/knowledge/patterns/strategy)** — Swap algorithms at runtime
5. **[Decorator](/knowledge/patterns/decorator)** — Add behavior dynamically
6. **[Adapter](/knowledge/patterns/adapter)** — Make incompatible interfaces compatible
7. **[Circuit Breaker Pattern](/knowledge/patterns/circuit-breaker-pattern)** — Prevent cascade failures
8. **[Consistent Hashing](/knowledge/patterns/consistent-hashing)** — Distribute data across nodes
9. **[CQRS](/knowledge/patterns/cqrs)** — Separate reads and writes
10. **[Event Sourcing](/knowledge/patterns/event-sourcing)** — Store state as events
