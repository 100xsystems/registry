# Frameworks

36 frameworks that provide structure and abstractions for building applications. Choose based on your language and use case.

## Top 10 Must-Know Frameworks

1. **[React](/knowledge/frameworks/react)** — UI library (most popular)
2. **[Next.js](/knowledge/frameworks/nextjs)** — Full-stack React framework
3. **[Django](/knowledge/frameworks/django)** — Python web framework (batteries included)
4. **[Express](/knowledge/frameworks/express)** — Node.js web framework
5. **[FastAPI](/knowledge/frameworks/fastapi)** — Python API framework (async, fast)
6. **[Spring](/knowledge/frameworks/spring)** — Java enterprise framework
7. **[Vue](/knowledge/frameworks/vue)** — Progressive UI framework
8. **[NestJS](/knowledge/frameworks/nestjs)** — Node.js enterprise framework
9. **[Flutter](/knowledge/frameworks/flutter)** — Cross-platform mobile
10. **[Tailwind CSS](/knowledge/frameworks/tailwind)** — Utility-first CSS
