# Software Principles

136 principles that guide how we write, design, and architect software. Start with the top 10, then explore by category.

## Top 10 Must-Know Principles

1. **[DRY](/knowledge/principles/dry)** — Don't Repeat Yourself
2. **[KISS](/knowledge/principles/kiss)** — Keep It Simple, Stupid
3. **[SOLID](/knowledge/principles/solid)** — Single Responsibility, Open/Closed, Liskov, Interface Segregation, Dependency Inversion
4. **[YAGNI](/knowledge/principles/yagni)** — You Aren't Gonna Need It
5. **[Fail Fast](/knowledge/principles/fail-fast)** — Detect errors early
6. **[Defensive Programming](/knowledge/principles/defensive-programming)** — Assume everything can fail
7. **[Graceful Degradation](/knowledge/principles/graceful-degradation)** — Reduce functionality under load
8. **[Circuit Breaker](/knowledge/principles/circuit-breaker)** — Stop cascade failures
9. **[Idempotency](/knowledge/principles/idempotency)** — Same operation, same result
10. **[CAP Theorem](/knowledge/principles/cap-theorem)** — Consistency, Availability, Partition tolerance
