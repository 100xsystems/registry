# WOLFRAM-01-GETTING-STARTED: Getting Started with Wolfram Language

## Introduction

Notebooks, evaluation, hello. By the end of this lesson you will be able to: Open a notebook; Evaluate expressions; Use the Wolfram Cloud; Write hello world.

## Key Concepts

### 1. Open a notebook

Target: Open a notebook. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```wolfram
Print["Hello, World!"]
```
### 2. Evaluate expressions

Target: Evaluate expressions. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```wolfram
1 + 1
```
### 3. Use the Wolfram Cloud

Target: Use the Wolfram Cloud. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```wolfram
2^10
```
### 4. Write hello world

Target: Write hello world. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```wolfram
Print["Hello, ", "Wolfram!"]
```
