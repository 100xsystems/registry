# SCRATCH-04-EVENTS: Events

## Introduction

Trigger scripts with events. By the end of this lesson you will be able to: Use event blocks; Broadcast messages; Receive broadcasts; Trigger on keys.

## Key Concepts

### 1. Use event blocks

Target: Use event blocks. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text
# Events > when green flag clicked
```
### 2. Broadcast messages

Target: Broadcast messages. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text
# Events > broadcast message1
```
### 3. Receive broadcasts

Target: Receive broadcasts. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text
# Events > when I receive message1
```
### 4. Trigger on keys

Target: Trigger on keys. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text
# Events > when space key pressed
```
