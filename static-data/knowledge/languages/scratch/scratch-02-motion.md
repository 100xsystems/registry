## Introduction

Move sprites on the stage. By the end of this lesson you will be able to: Move sprites; Point in directions; Use glide blocks; Change x and y.

## Key Concepts

### 1. Move sprites

Target: Move sprites. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text

# Motion > turn clockwise 15 degrees
```
### 2. Point in directions

Target: Point in directions. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text

```
### 3. Use glide blocks

Target: Use glide blocks. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text

```
### 4. Change x and y

Target: Change x and y. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text

# Motion > change y by -10
```
