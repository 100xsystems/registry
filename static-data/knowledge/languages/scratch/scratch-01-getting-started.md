# SCRATCH-01-GETTING-STARTED: Getting Started with Scratch

## Introduction

The editor, sprites, and your first project. By the end of this lesson you will be able to: Navigate the Scratch editor; Understand the stage; Add sprites; Run a project.

## Key Concepts

### 1. Navigate the Scratch editor

Target: Navigate the Scratch editor. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text
# Blocks: Events > When green flag clicked
# Motion > Move 10 steps
# Run: press the green flag
```
### 2. Understand the stage

Target: Understand the stage. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text
# Motion > glide 1 secs to x: 0 y: 0
```
### 3. Add sprites

Target: Add sprites. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text
# Looks > say Hello! for 2 seconds
```
### 4. Run a project

Target: Run a project. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text
# Control > wait 1 seconds
```
