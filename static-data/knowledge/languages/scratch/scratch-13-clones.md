# SCRATCH-13-CLONES: Clones

## Introduction

Duplicate sprites dynamically. By the end of this lesson you will be able to: Create clones; Start as clone; Delete clones; Use clone events.

## Key Concepts

### 1. Create clones

Target: Create clones. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text

```
### 2. Start as clone

Target: Start as clone. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.


Target: Delete clones. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text

```
