# SCRATCH-20-ADVANCED-PROJECTS: Advanced Project Ideas

## Introduction

Push Scratch further. By the end of this lesson you will be able to: Build simulations; Create art generators; Build music tools; Make complex games.

## Key Concepts

### 1. Build simulations

Target: Build simulations. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text
# Gravity simulator: balls with velocity and bounce
```
### 2. Create art generators

Target: Create art generators. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text
# Art: pen drawing with random colors on keypress
```
### 3. Build music tools

Target: Build music tools. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text
# Music: sequence notes from a list
```
### 4. Make complex games

Target: Make complex games. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text
# RPG: sprites, hp variables, battles, and story
```
