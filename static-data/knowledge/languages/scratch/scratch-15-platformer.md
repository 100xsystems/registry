# SCRATCH-15-PLATFORMER: Build a Platformer

## Introduction

Jumping and scrolling. By the end of this lesson you will be able to: Implement gravity; Detect ground; Add jumping; Handle scroll.

## Key Concepts

### 1. Implement gravity

Target: Implement gravity. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text
# Gravity: forever change y by -5
```
### 2. Detect ground

Target: Detect ground. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text
# Jump: if space pressed and on ground, set jump velocity
```
### 3. Add jumping

Target: Add jumping. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text
# Ground check: if touching platform, stop falling
```
### 4. Handle scroll

Target: Handle scroll. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text
# Camera: move the world sprites, not the player
```
