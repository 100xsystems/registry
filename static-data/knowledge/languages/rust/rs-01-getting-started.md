# RS-01-GETTING-STARTED: Getting Started with Rust

## Introduction

Install Rust, understand Cargo, create projects, write Hello World, and explore the toolchain.

## Learning Objectives

By the end of this lesson, you will be able to:

- Install Rust with rustup and set up the toolchain
- Create and build projects with Cargo
- Write and run a basic Rust program
- Explore standard library documentation
