# LABVIEW-01-GETTING-STARTED: Getting Started with LabVIEW

## Introduction

Front panel, block diagram, hello world. By the end of this lesson you will be able to: Understand the front panel; Understand the block diagram; Create a VI; Run a simple program.

## Key Concepts

### 1. Understand the front panel

Target: Understand the front panel. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```text
# LabVIEW VI: place a Numeric Indicator on the front panel,
# wire a Constant (e.g. 42) to it, and press Run.
```
### 2. Understand the block diagram

Target: Understand the block diagram. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```text
# Ctrl+E toggles front panel / block diagram.
```
### 3. Create a VI

Target: Create a VI. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```text
# Place a String Indicator; wire "Hello, World!" constant.
```
### 4. Run a simple program

Target: Run a simple program. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```text
# Press the Run button (white arrow) to execute.
```
