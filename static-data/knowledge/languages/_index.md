# Programming Languages

1113 language references organized by category. Don't try to learn everything — pick the right language for your role.

## Choose Your Language

### By Role (Quick Start)

| Role | Recommended | Why |
|---|---|---|
| **Frontend Engineer** | JavaScript/TypeScript | Browser native, React ecosystem |
| **Backend Engineer** | Python or Go | Fast development, great ecosystem |
| **ML Engineer** | Python | NumPy, PyTorch, TensorFlow |
| **DevOps Engineer** | Python + Bash | Automation, scripting |
| **Cloud Engineer** | Go or Python | Performance, cloud SDKs |
| **Data Engineer** | Python + SQL | Data manipulation, pipelines |
| **Systems Programmer** | Rust or C++ | Memory safety, performance |
| **Mobile Developer** | Dart (Flutter) or Kotlin (Android) | Cross-platform or native |

## Top 10 Must-Know Languages

1. **Python** — Most versatile, ML/data science standard
2. **JavaScript** — Browser native, full-stack potential
3. **TypeScript** — JavaScript with safety
4. **SQL** — Data querying (essential for all roles)
5. **Go** — Backend, cloud, DevOps
6. **Java** — Enterprise, Android
7. **Rust** — Systems, performance, safety
8. **C** — Foundational understanding
9. **Bash** — Scripting and automation
10. **Kotlin** — Modern JVM, Android
