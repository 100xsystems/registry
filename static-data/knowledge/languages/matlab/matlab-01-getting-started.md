# MATLAB-01-GETTING-STARTED: Getting Started with MATLAB

## Introduction

Desktop, command window, scripts. By the end of this lesson you will be able to: Navigate the MATLAB desktop; Use the command window; Create scripts; Run code.

## Key Concepts

### 1. Navigate the MATLAB desktop

Target: Navigate the MATLAB desktop. Start with the foundations — read the runnable example carefully and trace its output before moving on.

```matlab
disp("Hello, World!")
```
### 2. Use the command window

Target: Use the command window. Apply the idiomatic pattern — this is how production code expresses this idea, so study the shape of the code.

```matlab
% Run with F5 or the Run button in the editor
```
### 3. Create scripts

Target: Create scripts. Watch for the edge cases — this is where subtle bugs hide, and experienced developers reason about them explicitly.

```matlab
x = 42;
disp(x)
```
### 4. Run code

Target: Run code. Put it together — extend the example to combine this concept with what you learned in earlier lessons.

```matlab
name = "Ada";
fprintf("Hello, %s!\n", name)
```
