# Full-Stack Engineer Roadmap

A structured learning path covering both frontend and backend development, plus deployment and system design.

## Phase 1: Foundations (Weeks 1-6)

### Step 1: HTML, CSS, JavaScript
- Semantic HTML and accessibility
- Responsive design (Flexbox, Grid)
- JavaScript fundamentals (ES6+)
- DOM manipulation and events

**→ [Roadmap: Frontend Engineer (Phase 1)](/knowledge/roadmaps/frontend-engineer)**

### Step 2: A Backend Language
- **Node.js/TypeScript:** Full-stack JS, fastest path
- **Python:** Versatile, great for data-heavy apps
- **Go:** High-performance APIs

**→ [Languages: JavaScript](/knowledge/languages/javascript) | [Python](/knowledge/languages/python)**

### Step 3: Databases
- SQL with PostgreSQL
- Basic data modeling
- CRUD operations
- ORMs (Prisma, SQLAlchemy)

**→ [System Design: Databases](/knowledge/system-design/building-blocks-databases)**

## Phase 2: Core Full-Stack (Weeks 7-14)

### Step 4: React + Node.js
- React for frontend
- Express/Fastify for backend
- Building REST APIs
- Connecting frontend to backend

**→ [Roadmap: Frontend Engineer (Phase 2)](/knowledge/roadmaps/frontend-engineer)**

### Step 5: Authentication & Security
- JWT tokens
- OAuth2 flow
- Session management
- Input validation and XSS prevention

### Step 6: Git & Deployment
- Version control workflows
- Basic CI/CD
- Deploying to Vercel / Railway / AWS
- Environment variables and secrets

**→ [Roadmap: DevOps Engineer (Phase 2)](/knowledge/roadmaps/devops-engineer)**

## Phase 3: Scaling (Weeks 15-22)

### Step 7: Caching & Performance
- Redis for caching
- CDN for static assets
- Database query optimization
- Image optimization

**→ [System Design: Caching](/knowledge/system-design/building-blocks-caching)**

### Step 8: Advanced Backend
- Message queues for async work
- WebSocket for real-time features
- File storage (S3)
- Background jobs

**→ [System Design: Message Queues](/knowledge/system-design/building-blocks-message-queues)**

### Step 9: Testing
- Unit tests (Jest, Vitest)
- Integration tests
- E2E tests (Playwright)
- API tests

### Step 10: System Design Basics
- Scalability fundamentals
- Load balancing
- Database sharding

**→ [System Design: Fundamentals](/knowledge/system-design/fundamentals-scalability)**

## Phase 4: Advanced (Weeks 23-30)

### Step 11: TypeScript Mastery
- Advanced types
- Generics
- Type guards
- Monorepo tooling

### Step 12: Next.js / Full-Stack Frameworks
- Server-Side Rendering
- API routes
- Middleware
- Deployment patterns

### Step 13: DevOps for Full-Stack
- Docker basics
- CI/CD pipelines
- Monitoring and logging
- Incident response
