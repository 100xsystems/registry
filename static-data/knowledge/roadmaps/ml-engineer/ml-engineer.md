# ML Engineer Roadmap

A structured learning path for building and deploying machine learning systems in production.

## Phase 1: Foundations (Weeks 1-8)

### Step 1: Python & Data Science Libraries
- Python fundamentals
- NumPy, Pandas, Matplotlib
- Data manipulation and visualization
- Jupyter notebooks

**→ [Languages: Python](/knowledge/languages/python)**

### Step 2: Math Foundations
- Linear algebra (vectors, matrices)
- Calculus (derivatives, gradients)
- Probability and statistics
- Optimization basics

**→ [AI: Data Science Course](/knowledge/ai/data-science)**

### Step 3: Machine Learning Fundamentals
- Supervised learning (regression, classification)
- Unsupervised learning (clustering, dimensionality reduction)
- Model evaluation and validation
- Feature engineering

**→ [AI: Machine Learning Course](/knowledge/ai/machine-learning)**

## Phase 2: Deep Learning & Frameworks (Weeks 9-16)

### Step 4: Neural Networks
- Perceptrons and activation functions
- Backpropagation
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)

**→ [AI: Deep Learning Course](/knowledge/ai/deep-learning)**

### Step 5: Modern Architectures
- Transformers and attention mechanisms
- Pre-trained models (BERT, GPT)
- Transfer learning
- Fine-tuning techniques

**→ [AI: NLP Course](/knowledge/ai/nlp)**

### Step 6: ML Frameworks
- PyTorch (recommended for research)
- TensorFlow/Keras (production-friendly)
- Hugging Face Transformers
- Scikit-learn for classical ML

## Phase 3: Production ML (Weeks 17-24)

### Step 7: Model Serving
- REST APIs for inference (FastAPI)
- Model serialization (ONNX, TorchScript)
- Containerization with Docker
- GPU inference optimization

**→ [MLOps: Model Serving](/knowledge/ai/mlops/mlops-10-model-serving)**

### Step 8: MLOps Fundamentals
- Experiment tracking (MLflow, W&B)
- Model versioning and registry
- Data versioning (DVC)
- Pipeline orchestration (Airflow, Kubeflow)

**→ [MLOps Course](/knowledge/ai/mlops)**

### Step 9: Feature Engineering at Scale
- Feature stores (Feast)
- Real-time feature pipelines
- Feature validation and monitoring
- Batch vs streaming features

### Step 10: Model Monitoring
- Data drift detection
- Model performance monitoring
- A/B testing for models
- Feedback loops

## Phase 4: Specialization (Weeks 25-32)

### Choose Your Path
- **NLP/LLMs:** Transformers, fine-tuning, RAG, prompt engineering
- **Computer Vision:** Object detection, segmentation, image generation
- **Reinforcement Learning:** Q-learning, policy gradients, multi-agent
- **MLOps/Platform:** Building ML platforms and infrastructure

**→ [AI: Specialized Courses](/knowledge/ai/)**
