# DevOps Engineer Roadmap

A structured learning path for automating infrastructure, building CI/CD pipelines, and bridging development and operations.

## Phase 1: Foundations (Weeks 1-6)

### Step 1: Linux Fundamentals
- Command line proficiency
- File system navigation
- Process management
- Shell scripting (Bash)
- User and permission management

**→ [Tools: Linux-related](/knowledge/tools/)**

### Step 2: Networking Basics
- TCP/IP, DNS, HTTP/HTTPS
- Load balancing concepts
- Firewalls and security groups
- SSL/TLS certificates

**→ [System Design: Load Balancers](/knowledge/system-design/building-blocks-load-balancers)**

### Step 3: Programming
- Python or Go for automation
- Scripting for task automation
- API interaction (curl, requests)
- Git version control

**→ [Languages: Python](/knowledge/languages/python) | [Go](/knowledge/languages/go)**

### Step 4: Cloud Fundamentals
- Choose one: AWS / GCP / Azure
- Compute, storage, networking basics
- IAM and security
- Cost management

**→ [Tools: AWS](/knowledge/tools/aws)**

## Phase 2: CI/CD & Containers (Weeks 7-14)

### Step 5: Git & Version Control
- Advanced Git workflows
- Branching strategies (GitFlow, trunk-based)
- Code review processes
- Repository management

### Step 6: CI/CD Pipelines
- GitHub Actions / GitLab CI / Jenkins
- Build, test, deploy stages
- Pipeline as code
- Artifact management

**→ [MLOps: CI/CD for ML](/knowledge/ai/mlops/mlops-16-cicd-for-ml)**

### Step 7: Docker
- Containerization concepts
- Writing Dockerfiles
- Docker Compose for multi-container apps
- Container registries
- Image optimization

**→ [Tools: Docker](/knowledge/tools/docker)**

### Step 8: Container Orchestration
- Kubernetes fundamentals
- Pods, Deployments, Services
- ConfigMaps and Secrets
- Ingress controllers
- Helm charts

**→ [MLOps: Kubernetes Basics](/knowledge/ai/mlops/mlops-12-kubernetes-basics)**

## Phase 3: Infrastructure as Code (Weeks 15-20)

### Step 9: Infrastructure as Code
- Terraform fundamentals
- State management
- Modules and reuse
- CloudFormation / Pulumi alternatives

### Step 10: Configuration Management
- Ansible / Chef / Puppet
- Idempotent configurations
- Inventory management
- Playbooks and roles

### Step 11: GitOps
- ArgoCD / Flux
- Declarative infrastructure
- Drift detection
- Progressive delivery

## Phase 4: Monitoring & Reliability (Weeks 21-26)

### Step 12: Monitoring & Observability
- Prometheus for metrics
- Grafana for dashboards
- ELK Stack for logging
- Distributed tracing

**→ [System Design: Observability](/knowledge/system-design/)**

### Step 13: Incident Management
- On-call practices
- Runbooks and playbooks
- Blameless postmortems
- Communication during incidents

### Step 14: Security & Compliance
- Secret management (Vault)
- Container security scanning
- Network security
- Compliance automation

## Phase 5: Advanced Topics (Ongoing)

### Step 15: Chaos Engineering
- Failure injection
- Game days
- Resilience testing
- Steady-state hypothesis

**→ [Case Studies: Netflix Chaos Engineering](/knowledge/case-studies/netflix-streaming)**

### Step 16: Cost Optimization
- Resource rightsizing
- Reserved instances / savings plans
- Cost monitoring and alerts
- FinOps practices
