# Frontend Engineer Roadmap

A structured learning path for building modern web interfaces. Follow these steps from foundations to advanced topics.

## Phase 1: Foundations (Weeks 1-4)

### Step 1: HTML & Semantic Markup
- HTML5 elements and attributes
- Semantic HTML (header, nav, main, article, section)
- Accessibility (ARIA labels, screen readers)
- SEO fundamentals

**→ [Languages: JavaScript](/knowledge/languages/javascript)**

### Step 2: CSS Fundamentals
- Selectors, box model, positioning
- Flexbox and Grid layouts
- Responsive design (media queries)
- CSS variables and custom properties

### Step 3: JavaScript Core
- Variables, functions, closures
- DOM manipulation
- Events and event handling
- Promises and async/await
- ES6+ features (destructuring, modules, arrow functions)

**→ [Principles: DRY](/knowledge/principles/dry)**

## Phase 2: Modern Frameworks (Weeks 5-10)

### Step 4: React
- Components and JSX
- State and props
- Hooks (useState, useEffect, useContext)
- React Router for navigation
- Forms and controlled components

**→ [Frameworks: React-related](/knowledge/frameworks/)**

### Step 5: State Management
- Context API for simple state
- Redux or Zustand for complex state
- Server state: React Query / SWR
- When to use which

### Step 6: Styling Solutions
- CSS Modules
- Tailwind CSS
- Styled Components / CSS-in-JS
- Component libraries (Shadcn, MUI)

**→ [Tools: Tailwind CSS](/knowledge/tools/)**

## Phase 3: Tooling & Build (Weeks 11-14)

### Step 7: Build Tools
- Vite / Webpack
- Module bundling concepts
- Hot Module Replacement (HMR)
- Code splitting and lazy loading

### Step 8: Package Management
- npm / yarn / pnpm
- Semantic versioning
- Dependency management and security

### Step 9: Testing
- Unit testing (Jest, Vitest)
- Component testing (React Testing Library)
- E2E testing (Playwright, Cypress)
- Test-driven development (TDD)

**→ [Tools: Testing frameworks](/knowledge/tools/)**

## Phase 4: Advanced Topics (Weeks 15-20)

### Step 10: Performance Optimization
- Core Web Vitals (LCP, FID, CLS)
- Image optimization (WebP, lazy loading)
- Code splitting and tree shaking
- Service workers and caching

**→ [System Design: Caching](/knowledge/system-design/building-blocks-caching)**

### Step 11: TypeScript
- Type system fundamentals
- Generics and utility types
- Type guards and narrowing
- Integration with React

**→ [Languages: TypeScript](/knowledge/languages/typescript)**

### Step 12: Advanced Patterns
- Server-Side Rendering (SSR)
- Static Site Generation (SSG)
- Incremental Static Regeneration (ISR)
- Next.js / Remix

### Step 13: Design Systems
- Component architecture
- Design tokens
- Storybook for documentation
- Accessibility testing

## Phase 5: Specialization (Ongoing)

### Choose Your Path
- **Mobile:** React Native, Expo
- **Desktop:** Electron, Tauri
- **3D/WebGL:** Three.js, React Three Fiber
- **Data Visualization:** D3.js, Chart.js
