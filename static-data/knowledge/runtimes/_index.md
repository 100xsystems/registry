# Runtimes

6 JavaScript/TypeScript runtimes for server-side and edge computing.

## The Runtimes

### [Node.js](/knowledge/runtimes/nodejs)
- **The original** — Most mature, largest ecosystem
- **Use when:** You need npm packages, production stability
- **Best for:** Web servers, APIs, tooling

### [Deno](/knowledge/runtimes/deno)
- **Secure by default** — No file/network access unless granted
- **Use when:** Security matters, TypeScript native
- **Best for:** Edge functions, modern scripts

### [Bun](/knowledge/runtimes/bun)
- **Speed demon** — Written in Zig, fastest npm installer
- **Use when:** You want raw performance
- **Best for:** Fast builds, bundled tools

### [Cloudflare Workers](/knowledge/runtimes/cloudflare-workers)
- **Edge runtime** — Runs at 300+ locations globally
- **Use when:** You need low-latency at the edge
- **Best for:** API gateways, middleware, A/B testing

### [Vercel Edge Runtime](/knowledge/runtimes/vercel-edge)
- **Next.js native** — Tight integration with Next.js
- **Use when:** Deploying Next.js to the edge
- **Best for:** Serverless functions, edge middleware

### [WinterTC](/knowledge/runtimes/winter)
- **Web standards** — Standardized server JavaScript API
- **Use when:** You want portable server code
- **Best for:** Cross-runtime compatibility

## Choose Your Runtime

| Priority | Recommendation |
|---|---|
| **Ecosystem & stability** | Node.js |
| **Security** | Deno |
| **Performance** | Bun |
| **Global edge** | Cloudflare Workers |
| **Next.js deployment** | Vercel Edge Runtime |
| **Portability** | WinterTC |
