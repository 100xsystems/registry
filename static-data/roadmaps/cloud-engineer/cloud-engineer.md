# Cloud Engineer Roadmap

A structured learning path for designing, deploying, and operating cloud infrastructure.

## Phase 1: Foundations (Weeks 1-6)

### Step 1: Linux & Scripting
- Command line proficiency
- Bash/Python scripting
- Process and service management
- File systems and permissions

### Step 2: Networking Fundamentals
- TCP/IP, DNS, HTTP/HTTPS
- Subnets, CIDR, routing
- Firewalls and security groups
- Load balancing concepts

**→ [System Design: Load Balancers](/knowledge/system-design/building-blocks-load-balancers)**

### Step 3: Choose Your Cloud
- **AWS:** Largest market share, most services
- **GCP:** Strong in data/ML, Kubernetes-native
- **Azure:** Enterprise Microsoft integration

**→ [Tools: AWS](/knowledge/tools/aws)**

## Phase 2: Core Cloud (Weeks 7-14)

### Step 4: Compute
- EC2 / Compute Engine / VMs
- Auto Scaling Groups
- Container services (ECS, EKS)
- Serverless (Lambda, Cloud Functions)

### Step 5: Storage
- Object storage (S3, GCS)
- Block storage (EBS, Persistent Disk)
- File storage (EFS, Filestore)

### Step 6: Databases
- Managed relational (RDS, Cloud SQL)
- NoSQL (DynamoDB, Firestore)
- In-memory (ElastiCache, Memorystore)
- Data warehousing (BigQuery, Redshift)

**→ [System Design: Databases](/knowledge/system-design/building-blocks-databases)**

### Step 7: Identity & Access Management
- IAM roles and policies
- Service accounts
- Least-privilege access
- Multi-factor authentication

## Phase 3: Infrastructure as Code (Weeks 15-20)

### Step 8: Terraform
- HCL syntax and concepts
- State management (remote state)
- Modules and reuse
- Workspaces

### Step 9: CloudFormation / Pulumi
- Declarative infrastructure
- Stack management
- Drift detection
- Change sets

### Step 10: Container Orchestration
- Kubernetes on cloud (EKS, GKE, AKS)
- Managed Kubernetes services
- Cluster networking and storage
- Helm charts

**→ [MLOps: Kubernetes Basics](/knowledge/ai/mlops/mlops-12-kubernetes-basics)**

## Phase 4: Architecture & Security (Weeks 21-28)

### Step 11: Cloud Architecture Patterns
- High availability design
- Disaster recovery
- Multi-region architecture
- Cost optimization

**→ [System Design: Fundamentals](/knowledge/system-design/fundamentals-scalability)**

### Step 12: Security
- Encryption at rest and in transit
- WAF and DDoS protection
- Secrets management
- Compliance frameworks

### Step 13: Networking Advanced
- VPC design
- Private endpoints
- Transit Gateway
- DNS management (Route 53)

### Step 14: Observability
- CloudWatch / Cloud Monitoring
- Distributed tracing
- Cost monitoring
- Performance dashboards

## Phase 5: Certifications & Specialization

### Recommended Certifications
- **AWS:** Solutions Architect Associate → Professional
- **GCP:** Associate Cloud Engineer → Professional Cloud Architect
- **Azure:** AZ-104 (Administrator) → AZ-305 (Architect)
