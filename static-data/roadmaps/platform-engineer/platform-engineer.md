# Platform Engineer Roadmap

A structured learning path for building internal developer platforms that improve developer experience and delivery velocity.

## Phase 1: Foundations (Weeks 1-8)

### Step 1: Linux & Networking
- System administration basics
- Networking (TCP/IP, DNS, HTTP)
- Process management
- Troubleshooting skills

### Step 2: Programming & Scripting
- Python or Go for tooling
- Shell scripting
- API development
- Git version control

**→ [Languages: Python](/knowledge/languages/python) | [Go](/knowledge/languages/go)**

### Step 3: Cloud Fundamentals
- One cloud provider (AWS/GCP/Azure)
- Compute, storage, networking
- IAM and security
- Cost management

**→ [Tools: AWS](/knowledge/tools/aws)**

## Phase 2: Containers & Orchestration (Weeks 9-18)

### Step 4: Docker
- Container concepts
- Writing Dockerfiles
- Multi-stage builds
- Container security
- Docker Compose

**→ [Tools: Docker](/knowledge/tools/docker)**

### Step 5: Kubernetes Core
- Pods, Deployments, Services
- ConfigMaps and Secrets
- Namespaces and RBAC
- Ingress controllers

### Step 6: Kubernetes Advanced
- Custom Resource Definitions (CRDs)
- Operators
- Helm charts
- Cluster networking (CNI)
- Storage (CSI)

**→ [MLOps: Kubernetes Basics](/knowledge/ai/mlops/mlops-12-kubernetes-basics)**

### Step 7: Service Mesh
- Istio / Linkerd concepts
- Traffic management
- mTLS and security
- Observability

## Phase 3: CI/CD & GitOps (Weeks 19-24)

### Step 8: CI/CD Pipelines
- GitHub Actions / GitLab CI
- Pipeline design patterns
- Artifact management
- Testing in pipelines

**→ [MLOps: CI/CD for ML](/knowledge/ai/mlops/mlops-16-cicd-for-ml)**

### Step 9: GitOps
- ArgoCD / Flux
- Declarative infrastructure
- Sync and drift detection
- Progressive delivery (canary, blue-green)

### Step 10: Release Management
- Feature flags (LaunchDarkly)
- A/B testing infrastructure
- Rollback strategies
- Versioning strategies

## Phase 4: Developer Experience (Weeks 25-30)

### Step 11: Internal Developer Platforms
- Backstage portal
- Golden paths and templates
- Self-service infrastructure
- Service catalogs

### Step 12: Observability as a Service
- Centralized logging (ELK, Loki)
- Metrics aggregation (Prometheus)
- Distributed tracing (Jaeger, Tempo)
- Dashboards (Grafana)

### Step 13: Policy as Code
- OPA/Gatekeeper
- Kyverno
- Security policies
- Compliance automation

## Phase 5: Advanced (Ongoing)

### Step 14: Platform Reliability
- Multi-cluster management
- Disaster recovery
- Capacity planning
- Cost optimization

### Step 15: Developer Productivity Metrics
- DORA metrics
- Developer satisfaction surveys
- Lead time measurement
- Deployment frequency tracking
