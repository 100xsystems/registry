# Data Engineer Roadmap

A structured learning path for building data pipelines, warehouses, and analytics infrastructure.

## Phase 1: Foundations (Weeks 1-6)

### Step 1: SQL Mastery
- Complex queries and joins
- Window functions
- Query optimization
- Database design and normalization

**→ [Languages: SQL-related](/knowledge/languages/)**

### Step 2: Python for Data
- Pandas for data manipulation
- NumPy for numerical computing
- Data cleaning techniques
- Scripting for automation

**→ [Languages: Python](/knowledge/languages/python)**

### Step 3: Data Modeling
- Star schema vs snowflake
- Dimensional modeling
- Slowly changing dimensions (SCD)
- Data warehousing concepts

**→ [System Design: Databases](/knowledge/system-design/building-blocks-databases)**

## Phase 2: ETL & Pipelines (Weeks 7-14)

### Step 4: ETL/ELT Fundamentals
- Extract, Transform, Load concepts
- Batch processing patterns
- Data quality validation
- Error handling and retry

### Step 5: Orchestration
- Apache Airflow
- DAG design patterns
- Task scheduling and retries
- Monitoring pipelines

### Step 6: Data Quality
- Great Expectations / dbt tests
- Data profiling
- Schema validation
- Monitoring data freshness

### Step 7: File Formats & Storage
- Parquet, ORC, Avro
- Columnar vs row-based storage
- Compression strategies
- Partitioning strategies

## Phase 3: Scale & Streaming (Weeks 15-22)

### Step 8: Distributed Processing
- Apache Spark
- Parallel computing concepts
- Cluster management
- Performance optimization

### Step 9: Stream Processing
- Apache Kafka
- Real-time pipelines
- Windowing and aggregation
- Exactly-once semantics

**→ [System Design: Message Queues](/knowledge/system-design/building-blocks-message-queues)**

### Step 10: Data Warehousing
- Snowflake / BigQuery / Redshift
- Massively parallel processing (MPP)
- Query optimization
- Cost management

### Step 11: Modern Data Stack
- dbt for transformations
- Fivetran / Airbyte for ingestion
- Snowflake / BigQuery for warehousing
- Looker / Tableau for BI

## Phase 4: Advanced (Weeks 23-30)

### Step 12: Data Lake Architecture
- Data lake vs data lakehouse
- Delta Lake / Apache Iceberg
- Schema evolution
- Time travel queries

### Step 13: Real-Time Analytics
- OLAP databases (ClickHouse, Druid)
- Materialized views
- Sub-second queries
- Real-time dashboards

### Step 14: Data Governance
- Data cataloging
- Lineage tracking
- Access control
- Privacy and compliance (GDPR)

### Step 15: Data Platform
- Building internal data platforms
- Self-service analytics
- Data mesh concepts
- Federated governance
